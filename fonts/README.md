# Fonts

Every font the desktop uses, one folder per family. `bootstrap.sh fonts` installs them
(Linux: `~/.local/share/fonts/personal-infra`, macOS: `~/Library/Fonts`).

| Folder | Families | Used for | Source | Licence |
|---|---|---|---|---|
| `oldschool-pc/` | PxPlus IBM VGA 8x16, Ac437 IBM CGA | Latin monospace everywhere (`font-preset pixel`); Obsidian code | [Oldschool PC Font Pack](https://int10h.org/oldschool-pc-fonts/) | CC BY-SA 4.0 |
| `cubic-11/` | Cubic 11 | Chinese (`font-preset pixel`) | [ACh-K/Cubic-11](https://github.com/ACh-K/Cubic-11) | OFL 1.1 |
| `fuzzy-bubbles/`, `fuzzy-bubbles-mono/` | Fuzzy Bubbles (Mono) | `font-preset bubble`, Emacs variable-pitch, Obsidian | [Google Fonts](https://fonts.google.com/specimen/Fuzzy+Bubbles) | OFL 1.1 |
| `typicons/` | typicons | dwm status bar icons | [stephenhutchings/typicons.font](https://github.com/stephenhutchings/typicons.font) | OFL 1.1 |
| `symbols-nerd-font/` | Symbols Nerd Font Mono | dwm tag icons | [Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) | MIT |
| `recursive/` | Rec Mono Casual, Recursive Mono Casual Static | st; Obsidian code fallback | [arrowtype/recursive](https://github.com/arrowtype/recursive) | OFL 1.1 |
| `zcool-kuaile/`, `ma-shan-zheng/`, `long-cang/` | ZCOOL KuaiLe, Ma Shan Zheng, Long Cang | Obsidian Chinese fallbacks; st | Google Fonts | OFL 1.1 |
| `press-start-2p/` | Press Start 2P | Obsidian UI fallback | [Google Fonts](https://fonts.google.com/specimen/Press+Start+2P) | OFL 1.1 |
| `shantell-sans/`, `short-stack/` | Shantell Sans, Short Stack | Obsidian text fallbacks | Google Fonts | OFL 1.1 |
| `monofur-nf/` | Monofur NF | Obsidian code fallback | [Nerd Fonts](https://github.com/ryanoasis/nerd-fonts) (monofur by Tobias B. Köhler) | freeware, redistributed by Nerd Fonts |
| `monaspace-radon/` | Monaspace Radon Frozen | Obsidian code fallback | [githubnext/monaspace](https://github.com/githubnext/monaspace) | OFL 1.1 |

Not here: StarLovePencil (宅在家自動筆, `font-preset bubble` Chinese), licence unknown, so it is not published.
